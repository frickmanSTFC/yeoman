FAQ

What is Yeoman?

A companion page for Star Trek Fleet Command on PC. It shows your fleets, mining, loot history, build and research milestones, and battle results in a browser tab, updated while you play. A small mod inside the game writes the numbers to disk. Yeoman reads them and draws the page.

Does it send anything anywhere?

No. The mod writes files into a yeoman folder inside the game folder. The page is served on your own machine only, at localhost:8765. Nothing is uploaded.

The page is empty or says "waiting for game"

The game has to be running with the mod loaded. Start the game, wait for it to reach the galaxy, then press F5. If it stays empty, check that version.dll is in the game folder next to prime.exe. The Settings tab shows the mod status.

No icons, or names show as numbers

Icons and names come from the game's own cache on your PC. They can only be built after the game has run at least once. Run Yeoman again, or use the refresh buttons on the Settings tab. The first icon export takes a few minutes.

The game updated and nothing works

Every game update breaks the mod until it is rebuilt against the new game. Wait for a new Yeoman. Until then the page shows the last data it saw.

The battles folder is large

Each battle is saved as one file. On the Settings tab set "Keep for" to a lower number of days, or turn "Save battle journals" off. Old files are removed when the game next starts.

The alarm does not sound

Turn it on under Settings, then press "test sound". The browser tab must be open. Desktop notifications also need permission the first time; the browser asks for it when you tick the box.

Can I change the look?

Settings, then Theme. Four looks. The choice is saved in the browser.

Where are the files?

  • settings.json next to Yeoman.exe: the game folder.
  • data\ next to Yeoman.exe: names, icon index and icon images.
  • <game>\yeoman\: everything the mod writes.
  • <game>\version.dll: the mod. The one that was there before is kept as a .bak file.
  • <game>\community_patch_settings.toml: the mod's own settings, with a [yeoman] section.

How do I remove it?

Close the game. Delete version.dll from the game folder, or rename the .bak file back. Delete the yeoman folder in the game folder. Delete the Yeoman folder. That is all of it.
